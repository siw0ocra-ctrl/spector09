# Beginner guide

- First battle opens a paused, dismissible controls/growth/awakening guide.
- Camp and pause menu offer replay. Closing replay preserves the underlying pause and choices.
- First level-up includes a dismissible explanation; selecting a card also acknowledges it.
- First linked weapon/passive pair displays an awakening hint; pause lists live 5/3 progress.
- Skip suppresses all automatic guide hints. Browser-local seen flags persist independently of accounts; no server request or economy change.
- Achievements are intentionally deferred.

Validation: browser checks at 390×844 and 844×390 cover timer freeze, first choices, replay/ESC, reload persistence and skip. Existing client simulations pass for eight weapons and thirty boss/difficulty combinations. Build contains 109 assets.
